## 🚀 Почеток — Клонирај го проектот (без SSH клучеви!)

Овој репозиториум е **јавен** — не ти требаат SSH клучеви.
Користи HTTPS со следниов командов ред:

```bash
git clone https://github.com/[корисничкоИме]/digital-carnival.git
```

## 🔄 Git работен тек за студентите

```bash
# 1. Преземи ги последните промени
git pull

# 2. Отвори ја твојата датотека
#    students/[твоеИме]/index.html

# 3. Зачувај ги промените, па:
git add students/[твоеИме]/index.html

# 4. Направи commit со опис
git commit -m "Додадена анимација за [твоеИме]"

# 5. Прати ги промените на GitHub
git push
```

> **Забелешка за push:** При прв push ќе те побара корисничко
> име и лозинка. Наместо лозинка користи **Personal Access Token**
> (Settings → Developer settings → Tokens на GitHub).
> Алтернативно, користи **GitHub Desktop** — не бара никакви клучеви!
